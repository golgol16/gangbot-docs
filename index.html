Setting up the bot server admins

Everything from zero to fully running, in order. You need Discord Administrator permission in your server.

The bot does nothing until /setup is completed - every command just replies "This server is not set up yet".
Requirements - get these ready before running /setup👈 click to expand

Req 1 - Enable Developer Mode (for copying IDs)

  1. Open Discord User Settings (⚙️ next to your name) → Advanced → turn Developer Mode ON.
  2. With it on, right-clicking any role, channel, user or message shows Copy ID - that number is the UID.

You won't need IDs during /setup itself - it uses Discord's pickers where you select roles and channels from a list. IDs matter later for /editconfig values.

Req 2 - Have the roles ready

  1. Go to Server Settings → Roles and make sure you have a gang role - the role every active member carries. The bot pings this role for KOS declarations and the daily roster call, and it gates /sheets and /sticky. An existing "Active Roster" role works fine.
  2. Make sure you have a command role - your staff/leadership role, usually the role you use for your command chats. This one matters: it controls who can end a KOS, pick WON/LOST, edit war records, run /changeresult, and (unless you split them later) /pricelist, /weekly and /warns.

Req 3 - Create the channels

  1. War record channel (required) - where the bot logs every finished KOS with its WON/LOST result and attendance list. Usually locked so only the bot posts.
  2. Roster channel (optional) - the bot posts a roster call ping here every day at 4:00 PM Sydney time. Skip it if you don't want the daily ping. Channels like your gang chat can also work if you prefer to not make a dedicated channel
  3. Price channel (optional) - the bot keeps one auto-updating price list message here, refreshed from your sheet every 5 minutes. Skip it if you don't sell.
  4. In each of these channels the bot needs permission to View Channel, Send Messages, Embed Links and Add Reactions. If the channel is locked down, add the bot's role to the channel overrides.

Req 4 (Optional) - Share your Google Sheet with the bot (skip if your gang has no sheet)

The sheet is optional. Without one, everything works except the sheet-powered commands: /pricelist, /rules, /warns and /contactlist - they'll reply "needs a Google Sheet" until an admin adds one via /editconfig → Sheet ID.

  1. Open your gang's Google Sheet in a browser.
  2. Click the green Share button (top-right).
  3. Paste this email into the "Add people" box:
    drakos-bot@gothic-client-329620.iam.gserviceaccount.com
  4. Set the access to Viewer (the bot only reads, never writes) and click Share / Send. You can untick "Notify people".
  5. Copy the full sheet URL from your browser's address bar - you'll paste it into /setup in the next step.
Skipping this step is the #1 cause of "Failed to fetch" errors. The bot cannot see your sheet until it's shared.

Step 1 - Run /setup

Type /setup in any channel and fill in each box. Roles and channels appear as pickers - just select from the list.

Option Required Exactly what to put in
gangname ✅ Your gang's name as plain text, e.g. Drakos Family. Shown on embeds and used for war record titles ("YourGang V TheirGang - date").
gangrole ✅ Pick the gang role from Req 2 in the role picker.
commandrole ✅ Pick the command role from Req 2. Remember: this locks all staff commands.
warrecordchannel ✅ Pick the war record channel from Req 3.
sheetid optional Paste the full sheet URL you copied in Req 4. The bot extracts the sheet ID and saves the link for /sheets and /info automatically. Skip if your gang has no sheet.
rosterchannel optional Pick a channel to enable the daily 4 PM roster call. Leave empty = no roster call. Any channel can work.
pricechannel optional Pick a channel to enable the auto-updating price list. Leave empty = off.

Step 2 - Verify it worked

  1. Run /viewconfig - roles and channels should render as blue mentions (not raw numbers), and the four sheet ranges show (default).
  2. If you configured a sheet: run /rules rule:list or /contactlist - if data comes back, the sheet connection works. "Failed to fetch" = Req 4 wasn't done or the URL was wrong.
  3. Run a test /kos gang:Test, hit 🛑 End KOS, pick a result, and confirm it lands in your war record channel. Delete the test posts after.

Fine-tuning with /editconfig (optional)

Change any single setting with /editconfig setting: value:. For role/channel settings the value can be a mention (@Role / #channel) or a raw ID from right-click → Copy ID (Req 1). Common tweaks: split /pricelist//weekly//warns onto their own roles, set a Logo URL for /info, or adjust Roster Ranks to your gang's rank names.

Table-style rosters (one row per member)

If your roster is a table - each member on their own row, with rank, name and phone in separate columns - skip Roster Range / Roster Ranks entirely and instead set these three with /editconfig:

Setting Example Notes
Roster Rank Column Roster!C8:C40 The rank column. Start below the header row. Blank cells (merged ranks) inherit the rank above; repeated ranks are grouped together.
Roster Name Column Roster!D8:D40 The member name column. Rows with an empty name are skipped.

Once the rank and name columns are set, table mode takes over automatically. Roster Hidden Ranks still works if you want to keep certain ranks out of /contactlist.

Commands for everyone all members

No special role needed.

Command What it does
/kos Declare a KOS on an enemy gang. Options: gang (required), duration (grace period in minutes), starttime (Sydney time HH:MM - grace is worked out automatically), location.
/rules Look up a rule by code (e.g. S.1) or list for all rules & fines.
/contactlist The gang roster with names and phone numbers, by rank.
/info Post gang info: uniform code, KOS colors, gang status, sheets link.
/radio Post the radio frequency - pass a number, or randomfx for a random one.
/ping Check the bot is alive.

Reactions - how you check in

💀 On a KOS post: you went down during the KOS. The embed updates live.
⚔️ On a KOS post: you're attending the fight. Used for the war record attendance list.
✅ On a weekly post: you've paid your weekly. On the daily roster call: you're in for gang stuff today.

How a KOS runs, start to finish

  1. Someone runs /kos gang:Sierra Cartel. With a duration or starttime, it starts in a grace period (yellow) - do not engage yet. Without one, it's active (red) immediately.
  2. Members react ⚔️ attending and, if they get dropped, 💀 down.
  3. Grace ends automatically at the deadline - or staff hit ⚡ End Grace to go active early.
  4. When it's over, the caller or staff hit 🛑 End KOS, then answer the WON / LOST prompt.
  5. The bot logs the result to the war record channel - "YourGang V TheirGang - date", win/loss coloured, with the attendance list (⚔️ reactors minus 💀). Staff can fix attendance or flip the result later with the buttons on that post.

FAQ & troubleshooting

Commands don't show up in my server

Press Ctrl+R in Discord first - it caches the command list. If they're still missing, the bot may have just joined; commands are pushed on join, so give it a few seconds or ask the bot owner.

Where do I find an ID (UID)?

Enable Developer Mode (User Settings → Advanced → Developer Mode), then right-click any role, channel, user or message and pick Copy ID. For roles: Server Settings → Roles → right-click the role.

"This server is not set up yet"

An administrator needs to run /setup - nothing works before that. Full walkthrough in Setting up the bot.

Price list / rules / warns say "Failed to fetch"

Nine times out of ten: the sheet isn't shared with the service account (see Setting up the bot, Req 4), or the Sheet ID is wrong. Otherwise the range doesn't match your sheet's tab names - check /viewconfig.

The End KOS button says "interaction failed"

Try again - if the bot restarted recently it rebuilds the KOS from the message itself. Attendance/death lists gathered before a restart can't be recovered, so staff can fix the attendance on the war record post afterwards with ➕/➖.

Can other gangs see our data?

No - each server's config and sheet are completely separate, and no gang can ever see another gang's data.

Full transparency on who can see it: Gol (the bot's operator) runs the database and can read any sheet you share with the bot (read-only) plus the settings stored for your server. There's no workaround for this - it's how the bot works. If you're not comfortable with that, don't connect a sheet (it's optional), or don't use the bot.

What time is the roster call?

4:00 PM Sydney time (AEST), daily, in your configured roster channel. No roster channel configured = no roster call.

Who can end a KOS?

The person who declared it, or anyone with the command role. Same for choosing WON/LOST.
